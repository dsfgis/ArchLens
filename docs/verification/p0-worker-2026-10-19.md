## 交付范围

- 原生 LangGraph/PostgresSaver，`thread_id=runId`，独立 epoch namespace；只导入 Java 认可的应用状态，拒绝使用未认可的最新 checkpoint。同步持久化确保下一节点在认可完成后才执行。
- Java 核验版本、请求/目录 hash、调用、产物及结果原字节；以预期序号/hash CAS 推进认可指针和事件游标。取消、接管和失效租约阻止迟到变更。
- 显式 `P0_RULES_V1` 入队、持久轮询、180 秒租约和默认 20 秒心跳；稳定任务/动作身份及调用账本对账，复用原 invocation 和产物。
- V005 增加起算时间、运行 profile、TOOL/MODEL 预留/结算。逻辑工具调用只计一次，实际派发最多三次；停机时间计入总预算，接管不归零，未知派发不退款。旧 V001–V004 字节及校验和不变。
- 成功仅封存不可变 `PARTIAL / P0_SCOPE_ONLY` 回执；预算耗尽 PARTIAL，版本不兼容/数据漂移 FAILED。重复同内容封存返回原 hash，冲突拒绝。
- worker 的 checkpoint 连接只获该 schema 的 SELECT/INSERT/UPDATE；Java 仍拥有业务状态。该分工不隔离本机可信 OS 用户和启动环境。

### 故障和不变量

| 条件 | 实际断言 |
| --- | --- |
| 正常运行/重复封存 | 真实只读 list_rules，原生 checkpoint 至少 3 个；一个调用、一个封存事件；重复 hash 相同，冲突拒绝 |
| 工具登记后 SIGKILL | 新 epoch 导入认可状态，继续相同 invocation，预算仍只占一单位 |
| 工具结果持久后 SIGKILL | 从账本复用相同 artifact/result，不重新计费 |
| 原生 REGISTERED checkpoint 保存但未认可时 SIGKILL | 从旧认可指针恢复，忽略未认可的新 checkpoint |
| 封存前 SIGKILL | 导入成功状态后封存一次，保持调用/产物身份 |
| ENTRY 孤儿 checkpoint | 没有认可指针时从持久入口重建，不跟随 orphan |
| 并发/乱序 ACK、旧 epoch | 并发只有一个 CAS 成功；相同 ACK 幂等，旧序号拒绝；游标单调，新 epoch 后旧票据拒绝 |
| 续租/竞争领取 | 心跳保持租约，另一调度者不能领取；测试结束再人为过期以验证接管 |
| 取消后迟到 ACK | 拒绝旧票据，保持 CANCELLED，不产生成功终态 |
| 版本/数据漂移 | 不兼容版本、checkpoint 导出篡改、结果原字节篡改均失败关闭 |
| 预算 | MODEL 最后一单位并发只成功一个；幂等结算、接管不重置；工具三次派发上限；停机后时间耗尽保留预留并以 PARTIAL 收口 |
| 权限 | checkpoint 角色读取/修改业务表及创建表均被拒绝 |

CAS/漂移用例通过管理员连接改写合成测试数据注入故障；SIGKILL 通过测试专用子进程边界注入，生产 CLI 没有故障开关。这些测试证明固定工具协议，不构成任意 DAG、外部作业或生产安全隔离验收。

本轮一次运行因普通场景使用 100ms 测试心跳造成额外 JVM 开销，超过父测试 300 秒总时限，末尾两项取消。已让普通测试采用生产默认 20 秒，仅续租专项保留 100ms；未放宽断言或总时限。最终全部 24 项在约 201 秒完成。此前发现并修复异步 checkpoint 认可可能落后下一节点的问题，最终使用 `durability: sync`。

## 复现与依赖

从项目根目录，先启用 JDK 21 / Maven 3.9.x、Node 24+ 和可用的 Roslyn host；安装 Node 锁定依赖后运行：

```bash
(cd ArchLensService/agent-runtime && npm ci --ignore-scripts)
python3 ArchLensService/scripts/verify-p0.py
```

脚本默认 PostgreSQL 16 二进制目录 `/usr/lib/postgresql/16/bin`，可由 `ARCHLENS_TEST_PG_BIN` 覆盖。它禁用继承的外部集成测试开关，只启用自建测试库所需项目；使用合成密码和随机回环端口。测试集群不能以 PostgreSQL 不允许的 root 用户启动。运行/授权/命令细节见 [运行时 README](../../ArchLensService/agent-runtime/README.md)。

本次 Node 24.15.0、TypeScript 7.0.2；LangGraph 1.5.1、checkpoint-postgres 1.1.0、core 1.2.18、pg 8.23.1。直接运行时依赖为 MIT，TypeScript 为 Apache-2.0；锁文件传递依赖还含 BSD-3-Clause/ISC，详见运行时说明。LangSmith 为传递依赖，四个 tracing 环境开关均强制关闭；本原型不调用模型。
