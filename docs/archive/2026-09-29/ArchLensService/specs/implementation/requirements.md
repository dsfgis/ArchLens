## 1. 产品目标与范围

ArchLens 帮助工程人员回答：系统现在如何工作，目标变化有哪些兼容性差异，哪些对象和业务入口受影响，依据是什么，还缺什么证据，以及应该如何改造和验证。发现依赖不等于确认缺陷，提出替代方案不等于证明行为等价。

| 场景 | 调查范围 | 输出重点 |
| --- | --- | --- |
| 字段变更 | 列改名、删除、类型变化及上下游使用 | 直接引用、字段传播、契约影响 |
| 数据库替换 | 源/目标产品、版本、扩展、配置与访问方式 | 能力差异、SQL/驱动/事务依赖、切换及回退风险建议 |
| MySQL → PostgreSQL | 类型、方言、自增、标识符、排序规则、函数、事务、索引 | 版本适用的兼容问题、替代方案、验证清单 |
| Oracle → PostgreSQL | 上述维度及过程、包、触发器、同义词和特有语义 | 对象级问题、应用调用影响、人工决策项 |
| Oracle/MySQL → 人大金仓 | 源版本、KingbaseES 目标版本/兼容模式/配置、SQL、程序对象、驱动和访问依赖 | 独立金仓规则、应用改造范围、验证与切换建议；不直接套用 PostgreSQL 规则 |
| .NET 平台 → Java | .NET Framework/.NET Core/现代 .NET、语言、应用类型、框架、组件、数据访问及部署环境 | 模块迁移策略、替代方案、业务行为验证；当前只实现有限 C# 子集 |
| 信创改造 | 目标 CPU、操作系统、运行时、数据库、中间件及组件组合 | 组件替换、平台依赖和适配顺序；信创目标不自动推导为必须迁移 Java |
| 代码重构 | 模块拆分/合并、方法移动、接口调整、调用和状态/副作用 | 受影响模块、公共契约、不变量与回归范围 |
| 框架及依赖升级 | 版本接口、配置、传递依赖和行为差异 | 兼容性清单及影响路径 |

以上是目标场景目录，不是当前支持矩阵。每个版本必须声明实际覆盖的产品/语言版本、语法与对象种类；未覆盖场景也应能被明确拒绝或列为未知，不能模拟成功。

## 4. 非功能约束和排除范围

默认不读取业务行数据，不执行被分析项目的构建脚本、测试、存储过程或任意 SQL。Agent 可以建议用户在隔离环境运行验证并接收其结果，但该结果必须注明来源、环境和是否独立核实，不能冒充自身验证。

工具调用必须有参数校验、访问边界、取消和资源预算；数据源账号只读并限制元数据范围，数据库网络连接另需数据源授权。无权限、解析失败、版本未知和不支持语法均是可报告状态。分析只支持已覆盖的语义，不能以语言模型一般知识保证跨语言等价。

排除：自动代码转换或补丁应用、DDL/DML 执行、数据搬迁、数据库切换、生产部署、生产回滚。报告可以提出改造顺序、数据校验和回退检查建议，但不携带执行器或调用执行命令。ArchLens 自身存储建设与业务数据库迁移执行必须在名称和权限上区分。

## 6. 2026-09-24 目标驱动的平台分析需求（待实施）

以下 INV-REQ-10–16 扩展 INV-REQ-01–09。它们定义后续目标，不改变当前 v1 请求、C# 12 → Java 21 支持矩阵或已有 25 条规则的实际能力。对应设计、任务和验收分别见 [设计](design.md)、[任务](tasks.md)、[验收](check_list.md)。

### 输入与调查方式

基本输入为代码来源、按需提供的业务数据库连接和自然语言目的。代码来源支持本地授权目录及后续 Git 来源；Git 分析固定到提交，本地文件记录内容哈希。数据库填写产品、地址、库/schema、账号及凭据，敏感配置只交给受控后端，调查记录保存数据源引用；无数据库的项目允许仅分析代码。ArchLens 自身 PG/Neo4j 存储与业务数据源分别管理。

Agent 先探测技术栈，再询问影响结论的必要条件：目标平台及版本、金仓兼容模式、部署环境、接口与业务不变量、停机限制等。架构文档、接口定义和外部测试报告是可选补充来源。缺少目标条件时继续独立现状调查，对受阻结论保留 UNKNOWN。

### .NET 平台与组合场景

| 维度 | 目标识别范围 | 结果约束 |
| --- | --- | --- |
| 平台 | .NET Framework、.NET Core、现代 .NET；逐项目的目标框架及多目标配置 | 平台版本、SDK 版本和语言版本分别记录；.NET Standard 是共享 API 规范，不当作实际运行时 |
| 语言 | C#、VB.NET，以及待独立适配的其他 .NET 语言 | 语言与解析器支持矩阵逐项声明；C# 解析成功不表示 VB.NET/F# 等已支持 |
| 应用类型 | Web Forms、ASP.NET MVC/Web API、ASP.NET Core、WCF、Windows 服务、WinForms/WPF、类库等 | 按识别证据选择分析器；未覆盖应用类型列为缺口，不宣称完整平台支持 |
| 数据访问 | ADO.NET、EF6、EF Core、Dapper、驱动、SQL、存储过程调用 | 区分静态绑定、候选与动态未知；关注映射、事务、类型及序列化影响 |
| 依赖与部署 | NuGet、程序集、COM、原生库、IIS、配置、容器及操作系统依赖 | 缺源码/引用、条件配置和 Windows 专属依赖保留证据与限制 |

自然语言目的可拆为多个关联目标，例如“.NET Framework 到 Java + Oracle 到 KingbaseES + 指定信创环境”。Agent 分别调查后合并共享影响与前置依赖。只要求信创适配时，评估保留 .NET、平台升级或迁移 Java 的适用条件；不替用户决定必须更换语言。
